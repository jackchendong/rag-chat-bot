# shadcn-vue 界面开发

## 开始前

- 先阅读 `front/AGENTS.md` 和目标目录下的规范。
- 检查 `package.json`、`components.json`（如存在）、全局样式、别名配置和 `src/components/ui/`，确认真正可用的组件、主题和依赖。
- 当前可能只有规范文件。仅在任务明确要求初始化应用时建立工程；不要把参考项目的组件或配置当作已经安装。

## 实现选择

- 优先复用已安装的 shadcn-vue 组件及业务封装；缺少组件时先确认其 Vue 版本能力和项目配置，再决定是否引入。
- 示例与导入必须是 Vue API，不使用 React hooks、TSX 或 `className`，不假设 React 组件在 Vue 中有同名实现。
- 使用组件已有变体和语义色令牌；布局使用 Tailwind，条件类名复用项目已有的合并函数。
- 主题修改集中在现有全局样式或主题配置，不为局部需求重建主题系统。
- 组件新增或生成不得覆盖已有定制代码。确需调整基础组件时检查调用方，保留既有行为和可访问性。

## 本项目界面重点

- 聊天页将消息区、输入区和任务信息分离；窄屏仍能发送消息并查看任务详情。
- 消息区允许纵向滚动，长代码块在自身容器内横向滚动，不让整个页面横向溢出。
- 任务表单明确标注执行时间、频率和时区，并展示校验与提交失败信息。
- 任务状态使用可辨认的文字标签，不只靠颜色；结果尚不可用时区分待执行、执行中和失败。
- 弹窗、按钮和输入使用对应组件的可访问结构，检查标题、标签、焦点和键盘关闭行为。

## 验证

按实际脚本执行类型检查和构建。可运行界面时检查窄屏与宽屏、键盘导航、长消息和错误状态；无法运行时说明未验证的部分，不把截图或静态 mock 当作后端联调通过。
