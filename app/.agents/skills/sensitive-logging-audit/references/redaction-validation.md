# 脱敏验证清单

针对本次修改的真实日志调用边界选择场景，不要求为未实现的日志模式创建配置。

| 场景 | 需要验证的证据 |
|---|---|
| 模型请求、响应和任务内容 | 不含哨兵数据，且仍有必要的安全操作标识 |
| 授权头、API 密钥和外部 URL | 不输出凭据、秘密参数或含凭据的原始对象 |
| `args` 与 `extra` | 不附带敏感参数、字段或对象，即使渲染文本没有它们 |
| `exc_info`、`exc_text` 和异常链 | 不保存或格式化含秘密的异常、cause 或 context |
| `__str__` / `__repr__` 抛错或返回秘密 | 脱敏分支不读取敏感对象，不影响原本业务流程 |
| 自定义 handler 或遥测 exporter | 完整记录结构中没有残留敏感对象 |
| 取消、失败回退与资源清理 | 日志修复不改变这些可观察行为 |

检查 `record.msg`、`record.args`、`record.exc_info`、`record.exc_text`、额外字段及真实 Formatter 输出，不仅断言最终文本。Python 3.10 的异常链按当前版本验证，不要求实现更高版本的 ExceptionGroup。

审查结果记录输出位置、值来源、已确认/未确定分类、修复方式及验证。不要在审查报告中再次复制真实秘密；只使用安全占位符和代码位置。
