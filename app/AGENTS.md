# 后端项目概览

`app/` 是大模型对话 Demo 的 Python 后端，目标是支持普通对话、通过对话创建定时任务，以及后台调度和执行结果查询。前端位于 `../front/`；浏览器只负责交互和展示，不承担任务调度。

当前仅有 PyCharm 示例 `main.py`、本地 `.venv` 和编辑器配置，尚未实现 HTTP 服务、模型调用、任务存储或调度，也没有依赖清单和测试配置。不要把以下约定当作已经实现的功能。

本文件适用于 `app/` 及其子目录。参考 `nodelease` 的分层规范组织方式，但不继承其 Go、Redis 租约或发布约定。本次规范维护不要求初始化后端框架或修改示例程序。

## Python 技能

- 实现、修改或审查 Python 代码前，先阅读 `.agents/skills/python/SKILL.md`。
- 按根技能的路由表读取语言或工程流程技能，仅加载当前任务需要的部分。
- 工程流程参考 OpenAI Agents Python 官方技能，按本项目环境适配；不继承其 SDK 命令、发布流程或自动 worktree/commit 规则。
- 通用语言规则放在技能中；本文件维护项目职责、业务边界和运行环境，避免重复维护完整的 Python 教程。

## 环境与依赖

- 当前本地虚拟环境为 `app/.venv`，已检测解释器版本为 Python 3.10.11；在显式升级运行环境之前，代码兼容 Python 3.10，不使用更高版本专属语法或 API。
- 在 `app/` 工作目录下，Windows Python 路径为 `.venv/Scripts/python.exe`，Git Bash 可用 `./.venv/Scripts/python.exe`。不要误用全局解释器。
- `.vscode/settings.json` 用于打开 `app/` 文件夹时选择解释器和 Git Bash，不修改 `.bashrc`、系统 Python 或全局工具配置。
- 新增依赖前检查现有清单和锁文件。依赖管理方式尚未确定，不同时引入多套管理方案，也不为维护文档安装应用依赖。
- 不预先指定 FastAPI、Flask、数据库、模型 SDK 或调度框架；选择时结合具体需求，并更新实际依赖和运行文档。
- 不提交 `.venv/`、缓存、密钥、日志或本地运行数据。

## 组织与代码约定

- 保持当前实现简单；职责增长后再按需拆分请求入口、业务服务、模型适配、任务调度、持久化、配置和测试，不预建空目录。
- API 层负责输入校验和响应映射，业务层不依赖前端展示逻辑，模型和存储调用保持明确边界。
- 遵循已有代码风格；新增代码默认使用 4 空格缩进、snake_case 函数和变量、PascalCase 类、UPPER_SNAKE_CASE 常量。
- 优先标准库和已有依赖，类型与异常规则见 Python 技能，不为了单一调用增加复杂抽象。
- 不在模块导入时启动服务、调度器、网络请求或执行任务；客户端与后台资源通过明确生命周期创建和关闭。
- 若后续出现包结构，按实际导入方式提供启动命令，不通过临时修改 `sys.path` 绕过包设计。

## 普通对话契约

- 前后端接口路径、字段、错误和流式协议以实际实现及文档为准，修改可见契约时同步协调前端并更新 README。
- 模型凭据仅在服务端读取，不返回给浏览器，不记录到日志；配置缺失应明确失败，不伪装正常回复。
- 外部模型调用设置超时，区分取消、超时、限流和服务错误；重试有界，考虑调用成本及重复副作用。
- 会话和消息归属明确，不将所有用户的对话放入无隔离的全局列表。
- 模型输出是不可信内容，不能直接作为 Python、shell 命令或任意文件操作执行。
- 需要流式输出时明确事件格式、结束与错误语义，处理断连和资源清理；不承诺尚未实现的 SSE 或 WebSocket。

## 定时任务契约

- 区分自然语言任务草稿、用户确认、保存成功和执行成功。模型声称“已创建”不能替代真实存储成功。
- 创建前校验任务内容、执行方式、时间和时区；模糊信息先澄清，不默认采用服务器本地时区。
- 使用带时区的时间表示。对外明确时间格式及 IANA 时区；持久化时保留可恢复的周期规则和时区语义。
- 后台任务不能依赖前端页面存活，也不能仅依赖进程内临时列表声称支持重启恢复。
- 调度器在服务生命周期中显式启动和关闭，开发热重载或多个进程不能无意启动重复调度。
- 引入并行执行时明确任务认领、并发上限、超时、重试和幂等规则；没有保障时不能承诺“恰好一次”。
- 记录可查询的任务状态、执行时间、结果与失败原因；状态枚举及转换以实际接口契约为准。
- 服务重启后的恢复、错过执行时间和重复执行策略必须在实现时确定并写入文档，不能默默猜测。
- 仅执行项目明确支持的任务类型，不把用户输入转换为任意命令，不擅自扩展邮件、短信、RAG 或外部自动化能力。
