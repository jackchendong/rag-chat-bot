# Python 语法与惯用法

## 版本与类型

- 先确认目标解释器和项目类型检查配置，当前兼容 Python 3.10。不要使用 Python 3.11 的 TaskGroup、Python 3.12 的 `type` 别名语句等更高版本能力，除非运行环境已明确升级。
- 函数边界、共享数据和返回值提供有意义的类型标注。使用 `list[str]`、`dict[str, int]`、`str | None` 等兼容形式，不为了标注引入运行时依赖。
- 类型标注不是运行时校验。网络输入和反序列化数据在边界校验，未知数据先收窄类型，避免用 `Any` 或 `cast` 掩盖不确定性。
- 结构化值对象可使用 `dataclass`，字典协议可使用 `TypedDict`；不为每个临时字典创建类型体系。

## 函数与容器

- 不使用列表、字典或集合作为可变默认参数，改用 `None` 并在函数内创建对象。dataclass 的可变字段使用 `default_factory`。
- 区分 `None`、空集合、空字符串和合法零值。需要表达未提供时使用 `is None`，不让 `value or default` 覆盖合法输入。
- 用 `is` 比较 `None` 等单例，用 `==` 比较值，不用对象身份判断字符串或整数相等。
- 理解共享引用和浅拷贝；不用 `[[]] * count` 创建独立嵌套列表，不在遍历期间修改原集合结构。
- 推导式保持简短清晰，不借推导式执行副作用；大数据按需迭代，避免无必要地全部物化。
- 循环中创建延迟执行的回调时注意变量晚绑定，显式绑定所需值，不依赖循环结束后的变量状态。
- 函数名表达动作，参数明确含义；需要时使用关键字参数消除歧义，不引入无意义的 `*args`、`**kwargs` 转发。
- 生成器和迭代器可能只能消费一次；重复遍历前确认来源，`zip` 需要等长输入时在 Python 3.10 使用 `strict=True` 或明确校验，避免静默丢数据。
- 成员关系用集合或字典表达，只有查找规模和复用场景值得时才预建索引；不为了微优化牺牲清晰度。
- 装饰器需要保留被包装函数元信息时使用 `functools.wraps`；类和 property 仅用于真实状态或不变量，不把简单函数包装为无状态类。

## 异常与资源

- 捕获能够处理的具体异常，不使用裸 `except`。需要边界兜底时保留日志和失败状态，不返回伪成功值。
- 包装异常时按需使用 `raise ... from error` 保留原因，不让内部异常文本成为稳定 API 契约。
- 输入校验不用 `assert`，因为优化模式可能移除断言；无效输入抛出明确异常或映射为契约规定的错误。
- 文件、锁和其他资源优先使用 `with` 或 `async with`，否则用 `try/finally` 保证清理。
- 文本文件显式指定编码；路径使用 `pathlib` 等路径工具，不拼接机器专用目录分隔符。
- 日志使用参数化消息，不输出密钥或完整敏感对话；业务模块不用 `print` 代替已配置日志系统。
- `finally` 用于清理，不在其中 `return` 或覆盖原异常；清理失败不能悄悄掩盖主要失败原因。
- 外部数字输入明确范围和有限性，拒绝不允许的 `NaN`、无穷值。布尔值也是整数子类，校验计数或 ID 时不要意外接受 `True`。

## 时间与模块

- 区分带时区和无时区的 datetime，不混合比较。UTC 时间使用 `datetime.now(timezone.utc)`；IANA 时区使用 `zoneinfo`，Windows 上检查所需时区数据是否可用。
- 单次时刻与周期性本地时间规则分开处理，不用固定秒数模拟跨夏令时的每天同一当地时间。
- 导入采用明确来源，不使用通配符导入，不在导入时读取必须存在的秘密、发起网络请求或运行任务。
- 保留已有模块边界，不用 `eval`、`exec`、动态导入或字符串拼接命令执行用户和模型内容。
- 不反序列化不可信 pickle；JSON 解码只产生数据，不证明字段合法或适合直接调用业务函数。

复杂类型设计按需读取 [类型技能](../python-typing/SKILL.md)，不要通过增加注解掩盖运行时契约缺失。
