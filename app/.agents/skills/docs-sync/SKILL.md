# 文档同步

## 双向核对

- 先确定用户要求的主题或任务改动范围，不自动审查整个仓库，也不切换分支或创建 worktree。
- 文档到代码：验证相关说明中的入口、命令、字段、默认值和行为确实存在。
- 代码到文档：检查本次新增或改变的用户能力、环境要求、错误、时间语义是否有必要补充说明。
- 项目公开使用说明目前是仓库根目录 `README.md`；维护后端运行说明可以修改它，不因位于 `app/` 之外误判为禁止修改前端。
- 区分缺失、过时、错误和未来计划，保留当前“已实现/待实现”边界，不把规范目标写成可用功能。

## 本项目重点

- Python 版本、虚拟环境、依赖安装与真实启动入口。
- 模型配置及凭据保护，不在示例中出现真实密钥。
- 普通对话和流式协议的真实支持情况。
- 创建任务的确认、时间格式、时区、状态和结果查询。
- 调度持续运行、重启恢复、错过执行及重复执行的实际保证。

审查或建议请求只输出证据与建议，不擅自编辑。明确要求更新时直接完成范围内修改，未决行为先说明，不反复索要已经给出的授权。

纯文字修改检查格式和引用；涉及启动示例时仅在安全且环境可用时验证，不能为验证示例执行付费或带副作用的真实任务。不引入本项目不存在的文档构建系统。
